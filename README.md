## 💻 Comandos de Git Utilizados
Lista de comandos empleados durante el desarrollo del proyecto y el flujo de trabajo en equipo:

* `git init` - Inicializar el repositorio local.
* `git clone <url>` - Clonar el repositorio remoto.
* `git branch` / `git checkout -b <nombre>` - Crear y cambiar de rama (ej. `feature/responsive`, `feature/readme`).
* `git add .` - Agregar cambios al área de preparación (staging).
* `git commit -m "mensaje"` - Guardar los cambios con un mensaje descriptivo.
* `git push origin <rama>` - Subir la rama local al repositorio remoto en GitHub.
* `git pull` - Actualizar el repositorio local con los cambios del equipo.
* `git merge <rama>` - Fusionar las ramas de las funcionalidades terminadas.
